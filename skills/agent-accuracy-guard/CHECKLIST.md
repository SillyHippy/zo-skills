# COMMON SENSE CHECKLIST — EXECUTE BEFORE EVERY ACTION

Before doing ANYTHING, answer these 5 questions:

1. DID THE USER EXPLICITLY SAY YES/GO/APPROVE? 
   → If they asked for a plan first, STOP after the plan.
   → "I guess continue" = approval ONLY for the same pending action.

2. IS THIS THE RIGHT PROVIDER/MODEL?
   → Alibaba Coding Plan ≠ Command Code ≠ 9router ≠ OpenCode ≠ proxy.
   → Never use proxy output as evidence of Coding Plan availability.

3. AM I DELIVERING VIA THE RIGHT METHOD?
   → Telegram = send file attachment. NOT email. NOT summary.
   → Before claiming a file was sent, verify tool output shows attachment.

4. AM I RECOMMENDING SOMETHING BROKEN?
   → Meilisearch = DO NOT USE (RAM crashes).
   → Local GPU models = IMPOSSIBLE (no GPU).
   → More OCR = NOT NEEDED (already sufficient).

5. DID I VERIFY BEFORE CLAIMING DONE?
   → Open the file. Run the test. Check the output.
   → "I sent it" = verify attachment success in tool result.

IF ANY ANSWER IS "NO" OR "I DON'T KNOW" → STOP and verify before continuing.
